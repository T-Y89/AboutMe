### FDE（Forward Deployed Engineer）

顧客の現場に入り、課題整理から実装・運用定着までを一貫して担っています。

- サイト: https://souzou.dev/
- 美容室の業務改善
  - 約1週間現場に入り、接客・予約・バックオフィス全体の業務を再設計
  - カルテ作成: 月約20時間 → 約3時間（接客録音からAIが下書き、オーナーが確認）
  - 予約・問い合わせ対応: 月約8時間 → 約2時間（予約窓口を4種から2種へ整理し、既存の予約管理サービスとLINEに集約）
  - 売上は前月比20%増（予約件数・季節性の影響は未分離のため継続確認中）
  - 記事: https://note.com/souzou_dev/n/nd943188618ac
- コワーキングのコミュニティ基盤構築
  - 予約・掲示板・メッセージ・AIアシスタントを備えた基盤で会員機能と運営業務を統合。権限設計と運用手順まで整備
- 勤務管理システム
  - 勤怠・給与・スキル評価を一元化。夜勤・診療科・必要人数などの現場ルールを反映し、看護師・助手40名のシフトを数秒で自動作成
- 提案書作成基盤
  - 既存PowerPoint資産を活かしたスライド生成。国内保管・機密情報の扱い・品質チェックを含む内製基盤
